# Git Analytics

Analyze Git repositories and get quick insights about commits and authors.

### Features

- Total commits in the repository
- Commits per author with percentage contribution
- Commit activity by time (last hour, day, week, month, year)

### Setup & Usage

1. Clone the repository
2. Install dependencies : `pip install -r requirements.txt`
3. Run the script from the Git project directory you want to analyze, or provide its full path:
   `python main.py /full/path/to/git-project`
4. View Git analytics directly in your terminal.
