# Git Analytics

A simple tool to analyze Git repositories and extract useful statistics.

### 🔍 Features

- 📊 Total number of commits
- 👤 Commit statistics by author
- 🕒 Commit activity by time (hour, day, etc.)

---

### ⚙️ Setup & Usage

1. Clone the repository
2. Install dependencies : `pip install -r requirements.txt`
3. Run the script from the Git project directory you want to analyze, or provide its full path:
   `python main.py /full/path/to/git-project`
4. Done! View your Git analytics in the terminal.
